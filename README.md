# 🎨 React Color Picker

A simple color picker built with React.

Users can select a color, create a custom color and see the result instantly.

## Features

- Choose from predefined colors
- Enter a custom HEX color
- Live color preview
- Copy HEX code
- Color history

## Built with

- React
- JavaScript
- CSS
- Vite
